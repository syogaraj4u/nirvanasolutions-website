SCREENMINT · HELP CENTRE

Support

Start a screen recording

  1. Open ScreenMint and choose a recording quality. Balanced is the default.
  2. Select the audio mode you want.
  3. Tap the large record button.
  4. Confirm ScreenMint in Apple's broadcast interface and tap Start Broadcast.
  5. After the system countdown, leave ScreenMint and use the app or screen you want to capture.
iOS requires the confirmation and visible recording indication; ScreenMint cannot bypass them.

Stop a recording

Use the red recording indicator or supported system recording surface and choose Stop. Reopen ScreenMint to find the completed file in My Recordings. If a recording was interrupted, allow the app time to recover any completed segments.

System audio or microphone is missing

  • Confirm the selected audio mode before recording.
  • For microphone audio, allow Microphone access in iOS Settings and use the microphone level test.
  • Raise the media volume when testing system audio.
  • Some apps, calls and protected streaming media restrict audio capture.
  • Bluetooth routing and another app's active audio session can affect the result.
Make a 10-second test recording before an important session.

Choose recording quality

Storage Saver produces smaller files, Balanced provides a practical default, and Best Quality uses more storage and processing power. Pro mode allows manual resolution, bitrate, frame rate and codec settings. HEVC usually creates smaller files; H.264 is more broadly compatible.

Low storage, temperature or battery warnings

ScreenMint estimates file size and shows available storage before recording. Adaptive recording can lower bitrate or frame rate when storage, temperature or battery conditions become critical. Free storage space and let the device cool before a long high-quality recording.

Protected or black content

Video services, financial apps and other protected content can intentionally prevent capture. ScreenMint cannot override iOS or content-provider protection. A black area or missing audio in this situation is expected system behaviour.

Tap, key and face-camera limitations

Public iOS APIs do not provide system-wide touch or key events from other apps, so automatic cross-app tap and key highlighting is not available. Use ScreenMint's editor to add manual timed callouts. Likewise, iOS does not guarantee a persistent face-camera overlay above every other app; use the camera test before relying on camera-supported workflows.

Edit or export a recording

Open My Recordings, select a file and choose Edit. You can trim, crop, rotate, change volume, compress, merge, add text or drawings, blur sensitive details and add manual callouts. Export creates a new file so the original remains available. Use the share sheet, Photos or Files to choose a destination.

Recording or export failed

Check available storage, close other demanding apps, restart the device and make a short test recording. For export problems, try H.264 or a lower resolution. Do not remove the app while a recovery or export is in progress.

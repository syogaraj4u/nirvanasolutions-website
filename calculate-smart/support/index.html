CALCULATE SMART · HELP CENTRE

Support

Looking for Calculate+? The App Store product is named Calculate Smart. Its installed icon is labelled Calculate+; both names refer to the same app.

Edit any part of a calculation

Tap or drag inside the expression to place the cursor. Select digits or operators to replace, copy, cut or paste them. Results update while you edit, and holding backspace deletes continuously.

Switch calculators and converters

Use the calculator title or navigation menu to switch between Standard, Scientific, Fractions, Percentage, Currency and Unit Converter. Calculator modes and unit conversion work without an internet connection.

Use calculation history

Open History to search earlier calculations, reopen an entry, pin useful results, add a note or tag, duplicate an entry, or delete it. You can export selected or complete history as text or CSV. History is stored locally, and saving can be disabled or cleared in Settings.

Format and personalise the calculator

Settings includes device-default, Indian and international number grouping, automatic or fixed decimal places, app appearance, themes and button shapes. You can reset personalisation without creating an account.

Use Currency

Currency uses public Frankfurter reference rates. Open Currency and refresh when you want the latest available rates; the app may also refresh an older rate table when Currency is used online. Saved rates remain available offline. Currency results are estimates and can differ from banks, cards or exchanges.

Use Unit Converter

Select the source and destination units, swap them when needed, or use Show More to search the supported categories, including length, mass, area, volume, time, temperature, energy, power, pressure, speed, fuel efficiency and data size.

A calculation shows an error

Complete any missing number or closing parenthesis, then correct the highlighted part. Division by zero cannot produce a result. Very long pasted expressions can be rejected to keep the app responsive.

Currency refresh is unavailable

Confirm that the device is online and try again. If Frankfurter or the connection is unavailable, Calculate Smart continues using its newest saved rates. All calculator modes and unit conversion remain available offline.

Accessibility and keyboard help

Calculate Smart supports VoiceOver, larger text, increased contrast and reduced motion. With a physical keyboard on supported devices, number keys, operators, Return, Escape, Delete and arrow-key cursor movement are also supported.

Accounts and payments

Calculate Smart does not require an account, sign-in, subscription or payment. The app contains no advertising.
